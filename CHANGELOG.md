# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog][keep-a-changelog], and this project
adheres to [Semantic Versioning][semantic-versioning].

## [2.0.0] - 2026-08-19

### Added

- Add support for the `arm64` architecture

### Changed

- Run the action on Node 24
- Update `@actions/tool-cache` to v2.0.2

### Removed

- Remove support for 32-bit `x86`

### Fixed

- Fix the `version` input field

## [1.6.0] - 2025-01-02

### Changed

- Update `typescript` to v5.7.2

### Fixed

- Update the domain for itch.io's CDN

## [1.5.0] - 2024-10-21

### Changed

- Run the action on Node 20
- Update `@vercel/ncc` to v0.38.2
- Update `@actions/core` to v1.11.1

## [1.4.0] - 2023-10-02

### Changed

- Update `@actions/io` to v1.1.3
- Update `@vercel/ncc` to v0.38.0
- Update `@actions/core` to v1.10.1

## [1.3.0] - 2022-10-11

### Changed

- Update `@actions/core` to v1.10.0

## [1.2.0] - 2022-08-25

### Changed

- Update `@actions/core` to v1.9.1

## [1.1.0] - 2022-06-27

### Changed

- Update `@actions/core` to v1.8.2
- Update `@actions/tool-cache` to v2.0.1
- Update `@actions/core` to v1.9.0

## [1.0.0] - 2022-04-06

### Added

- Download butler and add it to the `PATH`
